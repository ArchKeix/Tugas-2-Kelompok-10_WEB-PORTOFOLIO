# Muhammad Rayhanza Barraq — Portfolio

A responsive one-page portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

## GitHub Pages

1. Create a GitHub repository and push this folder to the default branch.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
